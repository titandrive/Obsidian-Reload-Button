# Reload Button

A sidebar button that reloads Obsidian without saving: the same as the **Reload app without saving** command, one click away. Handy when you're working on plugins or themes.

The icon spins as it reloads.

## Install

Not on the community plugin store; install it with [BRAT](https://github.com/TfTHacker/obsidian42-brat):

1. Install and enable BRAT.
2. BRAT → **Add beta plugin** → `titandrive/Obsidian-Reload-Button`.
3. Enable **Reload Button** under Settings → Community plugins.

Or copy `main.js`, `manifest.json` and `styles.css` into `.obsidian/plugins/reload-button/` in your vault.
